# 第一版实施与验收 · 0.1.0

日期：2026-10-23。针对真实服务 `hr_assist/`；`prototype/` 为历史演示。

## 实施决定

- 群晖 x86_64 单容器，反向代理 HTTPS，单用户账号。
- 人事功能选择首页；第一期实现招聘模块。
- 人工表与自动总览分离，网页下载、Excel编辑、回传，避免互联网 SMB。
- 本地解析、日志、哈希、分数；获批模型仅接收去标识化文字和岗位要求。
- 反馈统计 → 用户修改评分细则 → 新JD版本 → 显式重评；不自动训练或调权。
