# 原型视觉与交互说明

本次采用 frontend-design 指导进行两遍设计：先确定信息结构和视觉语言，再检查原型是否贴合招聘工作的具体动作。

## 设计取向

- 色彩：纸白 `#FFFFFF`、浅灰蓝 `#F3F6F8`、文字深蓝 `#183443`、主色湖绿 `#16766F`、待办赭黄 `#986116`、异常红 `#AC4348`。
- 字体：Windows 的 Microsoft YaHei / 等线为正文，Segoe UI 为数字和英文。中文内容优先可读性，避免依赖外部字体加载。
- 排版：左侧稳定导航，中间为业务表格，候选人详情在同页独立证据区域展开。标题左对齐，数值用等宽数字特性。
- 特点：核心不是一个大聊天框，而是“这条推荐有什么依据、哪里待我处理”的清晰工作区。以简历片段和 JD 要求的成对证据作为最突出的交互。

```text
导航          当前模块标题                         演示标识
工作概览      最近批次与待办入口
候选人        筛选 ─ 申请列表 ─ 证据详情
岗位与 JD     JD 校验与岗位配置
报表与反馈    五个人工字段镜像 / 同步预览
运行记录      固定窗口与逐阶段结果
连接与设置    已确认选择与未配置项
```

评审后调整：不用通用大标题营销首页，也不把所有指标做成同样大小的卡片；工作概览突出“待我处理”，候选人模块突出证据与硬条件，报表模块突出人工字段只读与冲突处理。

## 原型已实现的交互

- 人事工作台首页作为默认入口，进入招聘助手后展示其六个业务页面；品牌标识和“工作台首页”均可返回全局入口。
- 招聘内部六个页面导航；候选人搜索、岗位和建议等级筛选。
- 候选人详情、五维得分、硬条件解释和成对证据。
- 报表页查看 Excel 人工字段，模拟同步一条明确标注的虚构变更。
- 演示“Excel 占用”与“关闭后写入”的流程；全部仅改变页面内存。
- 运行页查看模拟批次，重复演示不增加候选人数量。
- 设置页查看配置未就绪状态；不包含真实凭据输入或真实连接。

所有数据为虚构，不读取本机简历、邮箱、Excel 或 JD，不访问网络，不写入浏览器长期存储。刷新页面恢复初始演示状态。

## 全局入口的补充设计（2026-10-23）

信息层级调整为“人事工作台 → 招聘流程助手 → 工作概览 / 候选人库等业务页面”。沿用湖绿、浅灰蓝与现有中文字体，让新增入口与招聘模块保持连续。

首页突出唯一可预览的招聘功能，使用一个完整的功能区展示说明、能力范围和进入按钮；旁边列出该模块已有的演示任务摘要。员工档案、入转调离、考勤休假、薪酬社保、绩效培训只作为后续方向，标记“待规划”，没有可执行入口。

布局复核：保留稳定的全局返回入口；首页不展开招聘内部导航，不把招聘的六个页面当作六个人事模块。规划区不显示虚构业务数据或可点击的假功能。
